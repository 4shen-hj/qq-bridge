# 查看用量与费用

在控制台打开「令牌与花费」，选择会话查看逐轮明细，选择时间范围查看趋势。

## 理解统计口径

金额由本地价目配置折算，是估算值，不是服务商账单。内置价格与节假日不会自动保持最新，使用前核对自己的模型和计费规则。

- 累计用量包含 DSH 提供的历史总量，逐轮明细和图表只能覆盖桥接保留的采样。因此图表合计可能不同于累计金额。
- 没有逐时明细的历史累计按快照时刻的计价档位折算，不能还原实际峰谷分布。
- 未登记模型使用兜底价格并标为估算。重试也可能消耗 token，应计入使用成本。
- 修改价目配置会影响读取时的历史金额折算，不改变原始 token 记录。

## 配置价格

从 [config.example.json](../../config.example.json) 的 `pricing` 示例开始，只覆盖需要修改的项。`pricing.holidays` 是整表替换；自定义时需给出完整列表，不能只写新增日期。

实际价格、模型别名与峰谷计算以 [model-prices.js](../../src/model-prices.js)为准。账本的合并、去重与历史处理见 [token-ledger.js](../../src/token-ledger.js)，不根据 UI 截图或旧文档推断计费精度。

## 清空与验证

清空账本会丢失本地明细。后续同步仍可能恢复 DSH 的累计值，因此清空不等于把服务商用量归零。需要留档时先备份本机账本。

修改计价或账本后运行 `npm run test:tokens`；修改看板再运行[控制台浏览器回归](CONSOLE-UI-TESTING.md)。具体断言见 [test-token-usage.mjs](../../scripts/test-token-usage.mjs)。
